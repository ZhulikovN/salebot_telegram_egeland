# salebot_telegram_egeland


## 1. Цель интеграции
Обеспечить двустороннюю интеграцию между Salebot.pro и amoCRM, при которой:
при первом обращении клиента в бота создаются контакт и сделка в amoCRM;


диалог с клиентом отображается в сделке и в imbox;


менеджер может вести переписку с клиентом напрямую из amoCRM;


сообщения синхронизируются в реальном времени.

## 2. Общий сценарий работы
Клиент пишет в Telegram-бот, подключённый к Salebot.pro.


Salebot.pro передаёт данные клиента и сообщения в amoCRM.


В amoCRM:


создаётся или обновляется контакт;


создаётся сделка (при соблюдении условий недублирования);


диалог отображается в карточке сделки.


Менеджер отвечает клиенту из amoCRM (сделки).


Ответ уходит клиенту в тот же Telegram-канал через Salebot.pro.

## 5. Логика создания и обновления контакта
Контакт создаётся, если:
в amoCRM отсутствует контакт с таким TG ID или


отсутствует контакт с таким tg_username.


Контакт обновляется, если:
найден существующий контакт по TG ID или tg_username;


новые данные из Salebot.pro дописываются в существующий контакт.


Старые данные приоритетнее новых

## 6. Логика создания сделки

# 6.1 Общие правила
Сделка создаётся один раз при первом обращении клиента.


Повторные сообщения клиента не создают новую сделку, если обнаружен дубль.



# 6.2 Что считается дублем
Сделка считается дублем, если одновременно выполняются условия:
сделка принадлежит тому же контакту;


сделка находится в открытых этапах (кроме «Успешно» и «Закрыто»);


источник сделки — Salebot.pro;


сделка находится в той же воронке, в которой создаётся новая.



# 6.3 Что НЕ считается дублем
сделка этого же клиента уже закрыта (успешная или закрытая);


сделка находится в другой воронке.
